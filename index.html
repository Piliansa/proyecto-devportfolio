Juguetería Nico - Tienda Online

Página de venta online para la juguetería donde trabajo, en Concepción del Uruguay: catálogo, búsqueda y filtrado por categorías, y un flujo de pedido que conecta con WhatsApp para coordinar pago y entrega. Nace de una necesidad real de sumar un canal digital, y cada decisión responde a un problema concreto del negocio.

Next.js · TypeScript · Supabase · Vercel

Para relacionar imágenes de productos con el catálogo armé un sistema de matching por código y nombre normalizado, con puntaje de similitud para casos ambiguos y revisión humana obligatoria antes de subir nada a producción.

Automatización de carga de catálogo

Suite de scripts en Node.js para digitalizar el catálogo de la juguetería: desde el Excel que exporta el sistema de gestión del proveedor, hasta relacionar cada producto con su imagen y subirlo a la base de datos — sin perder el control humano en las decisiones que importan.

Node.js · Supabase · xlsx

La categorización de cada producto sigue una cascada de reglas (rubro → marcas 100% seguras → palabras clave del nombre → marca como respaldo), priorizando siempre la señal más confiable disponible. Para emparejar imágenes con productos armé un algoritmo de coincidencia por tokens, con puntaje ponderado (un número compartido pesa más que una palabra), y para los casos ambiguos genero un Excel de revisión: el script sugiere, pero soy yo quien confirma antes de que algo suba a producción.
